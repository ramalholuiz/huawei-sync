# M007 design workspace

Each cycle owns a self-contained set of documents:

- `cycle-NN-research.md` — visual research findings + reference table.
- `cycle-NN-directions.md` — three concepts (A refinement / B premium utility / C expressive motion) and the chosen direction with justification.
- `cycle-NN-motion-spec.md` — per-state motion spec (duration, easing, trigger, reduced-motion fallback).
- `cycle-NN-asset-manifest.md` — cycle-scoped asset provenance + APK-inclusion status.
- `cycle-NN-implementation-report.md` — what shipped, screenshots, motion frames, APK SHA-256, verification transcript.

The milestone plan lives at `docs/milestones/M007/PLAN.md`. Screenshots and captured evidence land under `docs/milestones/M007/screenshots/cycle-NN/`.
